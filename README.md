# 🚕 出租车网约车记账 APP (Taxi & Ride-Hailing Expense Tracker)

> **一线出租车司机独立开发｜ Built by an active taxi driver, for drivers worldwide.**

---

## 🇨🇳 项目简介

这是由一位**现役出租车司机**亲自开发、专为全球出租车与网约车同行打造的记账工具。

每天跑车的辛苦只有司机自己懂。复杂的流水结算、油/电成本计算、车辆保养以及零碎开支，都需要一款真正顺手、贴合实际场景的工具。

* **司机懂司机**：拒绝繁琐无用的功能，专注解决驾驶员每天真实的记账与收益统计痛点。
* **全球适用**：无论你是传统巡游出租车，还是 Uber、Lyft、Bolt 等网约车司机，均可免费使用。
* **开源共建**：欢迎提出意见、反馈 Bug，或提交代码交流！

---

## 🌎 About

This app is independently developed by an **active taxi driver** for taxi and ride-hailing drivers worldwide.

Only drivers truly understand what drivers need. Managing daily revenue, fuel/charging costs, and vehicle maintenance requires a simple, reliable, and straight-to-the-point tool.

* **Built for the Trade**: No bloated features—focused entirely on solving real daily tracking needs for drivers.
* **Global Ready**: Designed for all traditional taxi and ride-hailing (Uber, Lyft, Bolt, etc.) drivers around the globe.
* **Open Source**: Feature requests, bug reports, and code contributions are always welcome!
